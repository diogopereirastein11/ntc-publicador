Política de privacidade

Última atualização: 10 de novembro de 2026.

Dados que o app acessa

Com a autorização do titular, o app recebe do TikTok: o identificador da conta, o nome de exibição e a foto de perfil (para mostrar qual conta está conectada) e um token de acesso que permite publicar vídeos nessa conta.

Como os dados são usados

Exclusivamente para publicar, na conta do próprio titular, os vídeos que ele aprovou, e para consultar o status dessas publicações. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Armazenamento

O token de acesso é guardado como segredo cifrado no GitHub (GitHub Actions Secrets), fora do código e fora deste site. Os vídeos e legendas ficam no repositório privado do canal.

Dados de outras pessoas

O app não acessa seguidores, mensagens, comentários nem dados de outros usuários.

Exclusão

O titular pode revogar o acesso a qualquer momento no TikTok (Configurações → Segurança → Apps e serviços). Ao revogar, o token deixa de funcionar e é apagado dos segredos.
